# Catatan Perubahan

Semua perubahan penting proyek dicatat di sini.

## [0.1.0] - 2026-10-26

### Ditambahkan
- REST API modular FutsalBook dengan FastAPI dan kontrak Pydantic v2.
- PostgreSQL melalui SQLAlchemy dan migrasi Alembic.
- Autentikasi `X-API-Key` per pengguna dan otorisasi berbasis peran.
- Pengelolaan lapangan, pemesanan, pembayaran, serta pengguna.
- Pengujian otomatis, konfigurasi `.env`, lockfile, dan alur CI.
